Развёртывание Planka через GitHub

Этот гайд базируется на официальной документации Planka и показывает, как хранить инфраструктурные файлы в GitHub, автоматически деплоить их на сервер и сделать сервис общедоступным.

Что понадобится

  1. Аккаунт на GitHub и репозиторий (можно использовать текущий).
  2. Сервер с публичным IP и SSH-доступом.
  3. Установленные Docker и Docker Compose plugin.
  4. Доменное имя, указывающее на сервер (например, planka.example.com).

Структура репозитория

  • planka/docker-compose.yml — оркестрация Planka и PostgreSQL.
  • planka/.env.example — шаблон переменных окружения.
  • .github/workflows/planka-deploy.yml — GitHub Actions для доставки.
  • .gitignore — исключает приватный файл planka/.env.

Готовим файл .env

  1. Скопируйте planka/.env.example в planka/.env.
  2. Заполните URL сервиса, секретный ключ, данные администратора и параметры PostgreSQL.
  3. Добавьте SMTP-настройки, если нужна почта.
  4. Содержимое файла сохраните в секрете GitHub PLANKA_ENV_FILE.

Секреты GitHub

В разделе Settings → Secrets and variables → Actions добавьте:

  • PLANKA_ENV_FILE — содержимое planka/.env.
  • PLANKA_HOST — адрес сервера.
  • PLANKA_USER — SSH-пользователь.
  • PLANKA_SSH_KEY — приватный SSH-ключ.
  • PLANKA_REMOTE_PATH — путь вроде /opt/planka.

Подготовка сервера

curl -fsSL https://get.docker.com | sudo sh
sudo apt-get install -y docker-compose-plugin
sudo usermod -aG docker $USER
sudo mkdir -p /opt/planka
sudo chown $USER:$USER /opt/planka

Workflow GitHub Actions

Файл planka-deploy.yml выполняет следующие шаги:

  1. Чекаутит код.
  2. Создаёт planka/.env из секрета.
  3. Отправляет docker-compose.yml и .env на сервер через scp.
  4. Запускает docker compose pull и docker compose up -d.

Запустить его можно вручную или просто сделать commit/ push в ветку main.

Проксирование через Caddy

Создайте файл planka/Caddyfile на сервере и подключите его к Caddy:

planka.example.com {
  encode gzip
  reverse_proxy 127.0.0.1:1337
}

Проверяем результат

  1. Запустите workflow «Deploy Planka».
  2. На сервере выполните docker compose ps и docker compose logs -f planka.
  3. Откройте https://planka.example.com и войдите под админом.

Обновления и безопасность

  • После первого входа смените пароль администратора.
  • Для обновления версии измените тег образа в docker-compose.yml и перезапустите workflow.
  • Делайте резервные копии томов Docker: postgres-data, attachments и других.
